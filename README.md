## 🚀 Running Locally

If you'd like to run or preview this portfolio locally on your machine:

1. Clone this repository:
   ```bash
   git clone https://github.com/bjoynt2/bjoynt2.github.io.git
   ```
2. Navigate into the directory:
   ```bash
   cd bjoynt2.github.io
   ```
3. Open `index_optimized.html` or `index.html` in your preferred web browser. No local server or build step is required since the project uses Tailwind via CDN.

*(Tip: For the absolute best development experience, use the "Live Server" extension in VS Code).*
